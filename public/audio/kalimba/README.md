# Kalimba recordings

Music by Livia Zaharia: informal phone recordings of her own kalimba playing, not professional studio recordings. Used with her permission.

Six exact 58-second review clips were approved by Livia on 23 September 2026 as free of human voices. Clip 7 was rejected and is not distributed or referenced. Sources, edit times and SHA-256 hashes are in provenance.json. AAC, 96 kbps, stereo, gentle four-second fades and quiet loudness normalization. Total audio: approximately 4.2 MB.

The .m4a files are tracked with Git LFS. Deployment checkouts must run git lfs pull before building so actual audio files, not pointer text, reach public/audio/kalimba.
