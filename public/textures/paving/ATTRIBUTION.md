# Limestone paving

Original AI-generated paving colour texture, created for Livistone on 3 October 2026 with the built-in image-generation tool. It depicts weathered limestone slabs; it is not a measured scan or a photograph of a real location.

- `limestone-512.webp`: reduced graphics derivative, 512 px, WebP quality 86.
- `limestone-1024.webp`: rich graphics derivative, 1024 px, WebP quality 86.
- Original and generation brief: `concepts/03-landscape/`.

Both derivatives preserve the generated colour image, resized with Pillow Lanczos. No displacement is used. Rich paving uses the same image for subtle bump relief; reduced graphics samples only its colour. Geometric kerbs provide the actual road border depth.
